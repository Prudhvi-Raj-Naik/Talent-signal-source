# Talent Signal

AI recruitment + HR analytics prototype, built with React, Vite, Tailwind, and Recharts.
All data in the app is illustrative sample data (see the "How it works" tab).

## Run it locally

```
npm install
npm run dev
```

## Get it on a live URL (pick one)

**Fastest — no account needed:**
1. Run `npm install` then `npm run build`. This creates a `dist` folder.
2. Go to https://app.netlify.com/drop in a browser.
3. Drag the `dist` folder onto the page. You'll get a live URL in a few seconds.

**Permanent, with a custom domain and easy updates:**
1. Create a free GitHub account (if you don't have one) and a new repository.
2. Upload this whole folder to that repository (GitHub's "Add file → Upload files" works, or `git push` if you're comfortable with git).
3. Go to https://vercel.com, sign up free with your GitHub account, and click "Import Project."
4. Select the repository. Vercel auto-detects Vite and deploys it — no configuration needed.
5. You'll get a live `.vercel.app` URL in about a minute, and it auto-redeploys every time you push a change.

Netlify (https://netlify.com) works the same way as an alternative to Vercel, if you'd rather use that.
